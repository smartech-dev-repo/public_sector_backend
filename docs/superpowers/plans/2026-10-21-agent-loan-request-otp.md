# Agent-Assisted Loan Requests with Email-OTP Confirmation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an agent originate a loan request or top-up on behalf of a client they manage, with the client's consent captured either via the existing SMS-reply-YES flow (unchanged) or a new, parallel emailed OTP code that either the client or the agent can submit back.

**Architecture:** Add `confirmationCodeHash`/`confirmationCodeExpiresAt` columns to `LoanRequest` (same hashed/inline/TTL pattern as the existing Agent change-password OTP feature). `create`/`createTopup`/`resend` issue and email a fresh code alongside their existing SMS send. A new `confirmByCode` method validates the code and delegates to a `confirmPending` helper shared with the existing `confirmByPhone`, so both channels race to confirm the same `PENDING` row with identical downstream behavior (auto-approve/disburse under threshold). A new `agent/clients/:clientId/loan-requests...` controller mirrors the existing agent-ownership-scoping pattern, guarded by `AgentCanOnboardClientsGuard` since this is a consequential write. Every method that returns a raw `LoanRequest` row gets a scoped Prisma `omit` for the two new columns, since `confirmationCodeHash` is a single unsalted SHA-256 pass over a ≤100M-value space (trivially brute-forceable if ever leaked, unlike the bcrypt-hashed `Agent.passwordHash` precedent elsewhere in this codebase).

**Tech Stack:** NestJS, Prisma 7.10.0 (driver-adapter, custom client output at `src/generated/prisma/client`), Jest (unit + e2e via supertest), PostgreSQL (live shared UAT DB at `152.53.178.206`).

**Spec:** `docs/superpowers/specs/2026-10-21-agent-loan-request-otp-design.md`

## Global Constraints

- Hashing: `hashToken`/`generateOpaqueToken` from `src/common/opaque-token.util.ts` — unsalted SHA-256, no bcrypt.
- Code generation: `generateNumericCode(length)` from `src/common/generate-numeric-code.util.ts`.
- Code length: `EMAIL_CODE_LENGTH` config, default 6 (`Number(this.configService?.get('EMAIL_CODE_LENGTH') ?? 6)`).
- Dev echo: `devCodeEcho(configService, code)` from `src/common/dev-code-echo.util.ts` — returns the real code only when `EMAIL_CODE_DEV_ECHO === 'true'`, else `undefined`.
- TTL: 10 minutes (`LOAN_CONFIRMATION_CODE_TTL_MS = 10 * 60 * 1000`), matching the Agent change-password OTP precedent.
- Columns live inline on `LoanRequest` itself (`confirmationCodeHash String?`, `confirmationCodeExpiresAt DateTime?`) — not a separate OTP table.
- Wrong/expired code: `UnauthorizedException('Invalid or expired verification code')`.
- **Every** query that returns a raw `LoanRequest` row scalar-field set must add `omit: { confirmationCodeHash: true, confirmationCodeExpiresAt: true }` (a literal object, not a reference to the service's private static constant — test files outside the class cannot reference a `private static` member; this repo's existing tests for `LOAN_REQUEST_RELATIONS_INCLUDE` already follow this same literal-duplication convention).
- `confirmPending`'s two internal `update` calls (status→CONFIRMED, then status→DISBURSED) do **not** need the omit — their results are never returned to an API consumer, matching today's existing `confirmByPhone` behavior.
- `devCode: undefined` on a returned object is safe against existing `toEqual({...})` exact-match assertions — Jest's `toEqual` ignores `undefined`-valued keys (confirmed convention, reused from the Agent change-password OTP rollout).
- Migration naming: this project's most recent analogous migration is `20261019170623_agent_change_password_otp` (`YYYYMMDDHHMMSS_snake_case_description`, auto-timestamped by `prisma migrate dev --name <description>`).
- The DB is live and shared (UAT, `152.53.178.206`) — the migration must actually be applied there, not just generated locally and left unapplied.

```typescript
export function loanConfirmationCodeEmail(params: { code: string; ttlMinutes: number }): { subject: string; html: string; text: string } {
  const bodyText = `Hello,\n\nWe received a request to confirm your loan.\n\nYour verification code is: ${params.code}\n\nThis code expires in ${params.ttlMinutes} minutes. If you didn't request this, you can safely ignore this email — no loan will be confirmed.\n\n${CLOSING_TEXT}`;
  const bodyHtml = `<p>Hello,</p><p>We received a request to confirm your loan.</p><p>Your verification code is:</p>${highlightBox(params.code)}<p>This code expires in ${params.ttlMinutes} minutes. If you didn't request this, you can safely ignore this email — no loan will be confirmed.</p>${CLOSING_HTML}`;
  return {
    subject: 'Confirm your loan request',
    html: wrapEmailLayout({ headline: 'Confirm your loan request', bodyHtml }),
    text: wrapEmailLayoutText({ headline: 'Confirm your loan request', bodyText }),
  };
}
```

```typescript
import { Body, Controller, HttpCode, NotFoundException, Param, Post, Req, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from '../auth/jwt-auth.guard';
import { AgentOnlyGuard } from '../auth/agent-only.guard';
import { AgentCanOnboardClientsGuard } from '../auth/agent-can-onboard-clients.guard';
import { JwtPayload } from '../auth/jwt-payload.interface';
import { PrismaService } from '../prisma/prisma.service';
import { LoanRequestService } from './loan-request.service';
import { CreateLoanRequestDto } from './dto/create-loan-request.dto';
import { ConfirmLoanRequestCodeDto } from './dto/confirm-loan-request-code.dto';

@Controller('agent/clients/:clientId/loan-requests')
@UseGuards(JwtAuthGuard, AgentOnlyGuard, AgentCanOnboardClientsGuard)
export class AgentLoanRequestController {
  constructor(
    private readonly prisma: PrismaService,
    private readonly loanRequestService: LoanRequestService,
  ) {}

  private async assertOwnsClient(clientId: string, agentId: string): Promise<void> {
    const owned = await this.prisma.client.findFirst({
      where: { id: clientId, onboarding: { onboardedByAgentId: agentId } },
      select: { id: true },
    });
    if (!owned) {
      throw new NotFoundException('Client not found');
    }
  }

  @Post()
  async create(@Param('clientId') clientId: string, @Body() dto: CreateLoanRequestDto, @Req() req: { user: JwtPayload }) {
    await this.assertOwnsClient(clientId, req.user.sub);
    return this.loanRequestService.create(clientId, dto.amount, dto.tenorMonths);
  }

  @Post('topup')
  async createTopup(@Param('clientId') clientId: string, @Body() dto: CreateLoanRequestDto, @Req() req: { user: JwtPayload }) {
    await this.assertOwnsClient(clientId, req.user.sub);
    return this.loanRequestService.createTopup(clientId, dto.amount, dto.tenorMonths);
  }

  @Post(':id/resend')
  @HttpCode(200)
  async resend(@Param('clientId') clientId: string, @Param('id') id: string, @Req() req: { user: JwtPayload }) {
    await this.assertOwnsClient(clientId, req.user.sub);
    return this.loanRequestService.resend(clientId, id);
  }

  @Post(':id/confirm-code')
  @HttpCode(200)
  async confirmCode(
    @Param('clientId') clientId: string,
    @Param('id') id: string,
    @Body() dto: ConfirmLoanRequestCodeDto,
    @Req() req: { user: JwtPayload },
  ) {
    await this.assertOwnsClient(clientId, req.user.sub);
    await this.loanRequestService.confirmByCode(clientId, id, dto.code);
    return { confirmed: true };
  }
}
```

```typescript
      const createRes = await request(app.getHttpServer())

        .set('Authorization', `Bearer ${agentAccessToken}`)

      expect(['CONFIRMED', 'DISBURSED']).toContain(confirmedRequest.status);
```
